- PDF / Chop etish tugmasi brauzerning print oynasini ochadi.
- Telefon va email havolalari ishlaydi.

Eslatma: tashqi Google Fonts internet bo‘lganda yuklanadi; qolgan sayt lokal ishlaydi.
